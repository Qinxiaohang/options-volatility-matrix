## options-volatility-matrix
基于波动率与市场状态识别的期权矩阵交易系统 | 量化回测 + 实盘交易一体化框架
本项目是一套专注期权波动率交易、适配多市场行情的量化策略系统，核心围绕市场状态甄别+分层行情策略构建，覆盖底部震荡、底部突破、顶部衰竭三大核心行情场景。系统集成数据采集、策略逻辑、量化回测、实盘对接、风控计算全链路，解决传统期权交易主观判断、风险不可量化、极端行情无兜底的核心痛点，可直接用于历史回测验证与模拟/实盘自动化交易。

---
## 项目核心特性
- 多行情状态自适应：精准识别低波震荡、放量突破、顶部滞涨三类核心市场结构，不同行情匹配专属期权组合策略
- 波动率矩阵交易核心：依托隐含波动率IV、市场周期状态，构建高胜率的期权买卖对冲组合，兼顾收益与风险对冲
- 极端行情风控建模：支持单边暴涨/暴跌极端场景回测，量化跳空踩踏、保证金上调、展期损耗、价差浮亏四重风险
- 回测&实盘一体化：一套代码兼容量化回测验证、模拟盘测试、实盘自动化交易，无缝切换
- 模块化高可扩展：功能解耦，数据、策略、回测、实盘、工具模块独立，支持自定义策略迭代与参数优化

## 核心策略体系
项目通过 regime_filter.py 实时甄别当前市场状态，自动匹配对应交易策略，实现行情全覆盖、策略自适应：
1. 底部低波震荡策略（bottom_osc）
适配市场低位缩量、波动率低迷的震荡行情，采用期权双卖为主、低多高空为辅的组合思路，赚取波动率时间价值，依托网格加仓逻辑摊薄成本，适配震荡磨底的长期行情。
2. 底部放量突破策略（bottom_break）
适配底部企稳、成交量放量、趋势反转突破行情，核心逻辑为现货/标的做多+远月看涨期权买入+近月看跌期权对冲，捕捉趋势上涨收益，同时控制突发回撤风险。
3. 顶部衰竭策略（top_exhaust）
适配高位放量滞涨、上涨动能衰竭行情，采用顺势做空+远月看跌期权买入+近月期权对冲组合，抓取顶部回落行情收益，规避单边拉升跳空风险。

## 风控与回测能力
本系统重点解决期权杠杆交易的隐性风险，可量化测算极端行情下的策略生存底线：
- 模拟历史极端行情：2020市场暴跌、2022地缘暴涨等单边极端场景
- 四重压力量化测算：价差浮亏、跨期展期损耗、交易所/券商提保、行情跳空踩踏
- 精准计算账户动态权益、强平阈值，反向推导三级资金分层配置方案
- 规避倒金字塔加仓、制度性提保双杀、展期基差磨损等实盘常见爆仓陷阱

## 环境部署与使用
1. 环境安装
# 安装依赖
pip install -r requirements.txt
2. 项目配置
修改 config.yaml 配置文件，填入：交易API密钥、目标交易标的、仓位比例、风控止损阈值、保证金参数等核心配置。
3. 运行方式
# 启动历史回测
python main.py --mode backtest

# 启动模拟盘交易
python main.py --mode demo

# 启动实盘自动化交易
python main.py --mode live

## 项目说明
本系统为量化研究与实盘交易工具，所有策略均经过极端行情压力测试，以数据为核心划定交易安全边界，杜绝主观抄底摸顶。用户可基于本框架自定义策略参数、新增行情模型、优化风控逻辑，适配不同品种、不同周期的期权交易场景。
风险提示：历史回测数据不代表未来收益，实盘交易请严格把控仓位，做好资金分层管理与风险对冲。
